CodeHorizon is the home of independent software by **[Yuvaraj Vodiboina](https://github.com/yuvarajvodiboina)**. I build browser extensions and Android apps, handling the interface, platform integration, store release, and subsequent updates.

## Released products

| Product | What it does | Explore |
| :--- | :--- | :--- |
| **ShopGrade** | Audits public Shopify storefronts and organizes findings into evidence and next actions. | [Project](https://codehorizon.in/products/shopgrade/) / [Chrome Web Store](https://chromewebstore.google.com/detail/shopgrade/aenccbnkkimncdjikjgapconaegnmbeo) |
| **TubeFocus** | Hides YouTube distractions and keeps focus-session settings across page navigation. | [Project](https://codehorizon.in/products/tubefocus/) / [Chrome Web Store](https://chromewebstore.google.com/detail/ghmoajebamiileeffdiplohlbgnhnadl) |

## Engineering behind the products

The recurring problems are practical: preserving extension state during navigation, handling text selections across DOM nodes, reopening saved tab URLs, and making Android features useful offline. My [developer profile](https://github.com/yuvarajvodiboina) describes how I handled these problems in the released products.
